# 套装之王 SuitKing

面向《最终幻想 XIV》投影台与收藏柜的 Dalamud 插件，整理随身装备。

**当前版本为早期测试版（0.1.0.26）**。

[查看更新记录](CHANGELOG.md)

## 当前功能

- 打开投影台，自动汇总物品栏和兵装库中的套装装备，区分已保存、可补齐和未建立，默认显示“可补齐”。
- 勾选“隐去套装中的物品”，隐藏已登记到职业配装的装备；原生装备列表中的可补齐装备会标红。
- 点击“自动补齐”静默补入已有套装，同套缺件合并处理；点击“建立套装”为未被过滤的“未建立”装备创建套装，只有一件部件也可建立。运行中再次点击对应按钮可停止。
- 可存但尚未收录的装备显示“可存收藏柜”，提示优先处理；打开收藏柜后，点击“一键存入收藏柜”批量收纳。收藏柜功能始终忽略穿戴和职业配装中的装备，重复副本跳过自动收纳。
- NQ 部件与已有 HQ 套装不匹配时显示“品质冲突”。点击“冲突转 NQ”，预览并确认后自动取出 HQ 部件、关闭投影台降为 NQ，再重新打开并一起存回，每次处理一套。降品质不可恢复，中途停止的装备留在物品栏。

收藏柜请切到“存入”界面；收录数据尚未加载时先打开一次收藏柜。自动补齐和建立套装都会消耗幻象棱晶；已提交的操作仍可能完成。输入 `/sking` 或 `/suitking` 可开关窗口。

## 安装方法

1. 输入 `/xlsettings`，进入 **插件 → 第三方插件**。
2. 添加以下库链，勾选启用并保存：

   ```text
   https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
   ```

3. 输入 `/xlplugins`，搜索 **套装之王** 或 **SuitKing**，安装并启用。

## 适配与使用条件

需要已启用 Dalamud 的游戏环境。当前版本针对 **Dalamud API 15** 构建，使用国服 XIVLauncherCN 的开发程序集与本机国服物品数据验证套装映射。

已通过编译、跨分页汇总回归检查及国服套装数据核对。原生 UI 的显示、滚动、主题与缩放、关闭和卸载表现仍需游戏内验收。其他区服尚未验证；游戏或 Dalamud 大版本更新后，请以插件管理器中的兼容状态为准。

普通用户通过插件管理器安装即可，无需自行编译。源码构建、测试及开发加载说明见[开发文档](docs/development.md)。
